# Fintrack

Aplicacao de controle financeiro pessoal com API Node e frontend React.

## Requisitos

- Node.js 18 ou superior
- npm 9 ou superior

## Rodar localmente

Em um terminal:

```bash
cd backend
npm start
```

Em outro terminal:

```bash
cd frontend
npm install
npm run dev
```

Abra o endereco exibido pelo Vite (normalmente `http://localhost:5173`). A API roda em `http://localhost:3333`.

Os dados do backend sao mantidos em memoria e voltam ao estado inicial quando o processo reinicia.
